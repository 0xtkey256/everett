A one-character bug in a map-tile library sends a satellite-imagery pipeline to the wrong hemisphere — every image of Tokyo comes back as open ocean. Everett launches 32 parallel worlds on Daytona, lets an open coding model on Nosana try a different fix in each, and shows the satellite image every world actually fetches. The tests decide which world is real; the other 31 are thrown away.
